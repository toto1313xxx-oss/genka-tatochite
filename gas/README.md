# 伏見堂 原価符牒計算機 r3.1.1

移行済みシートに紐づくプロジェクトに Code.gs と appsscript.json を保存し、setupFushimidou を実行する。実行ユーザーを所有者、アクセス範囲を全員としてウェブアプリをデプロイする。

端末では同じ /exec URL を使用する。接続トークンは不要。URLを知る利用者は業務データを閲覧し、見積・原価の登録、マスタ更新、差戻し、取消を実行できる。起動PINは端末内の画面ロックで、APIのアクセス制御には使用しない。

台帳は追記型。取消も記録として保存する。操作IDによる再送確認、残額・マスタ版の照合、書き込み前の fushimidou-r3 接続先確認を行う。担当区分 shared は共有アクセスを示す。
